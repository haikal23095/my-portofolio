Gambaran Umum

Website Desa Sidomojo adalah platform informasi yang dibuat untuk membantu warga dan pengunjung mengakses profil desa, pengumuman publik, layanan, serta informasi penting lainnya dalam satu tempat. Proyek ini dikembangkan menggunakan Laravel dan Tailwind CSS untuk menciptakan tampilan yang bersih, responsif, dan mudah dipelihara.

Fitur Utama
  • Profil dan Gambaran Umum Desa
  • Berita dan Pengumuman Publik
  • Informasi Layanan Desa
  • UI Responsif untuk Mobile dan Desktop
  • Tata Letak yang Ramah untuk Admin
